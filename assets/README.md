# FischMate brand assets

- `fischmate-logo-source.jfif` is the original artwork supplied by the project owner.
- `fischmate-icon-256.png` is a center-cropped, resized application icon derived from that exact source.
- `fischmate-logo-square.png` is a built-in image-generation adaptation retained as an optional square brand asset.

The application currently uses `fischmate-icon-256.png` for its window icon and header.
