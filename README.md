# FischMate Free

FischMate Free includes rods that use the standard fishing mechanics and standard visual colors. Rods that require special colors, custom detection, or unique mechanics are shown in the rod picker with a crown and are available with **FischMate Full Access** at FischMate.com.

## Start

1. Double-click `Setup FischMate.vbs`. This will automatically download the necessary Python libraries listed in `requirements.txt`.
2. Open `FischMate.vbs`.
3. Select your rod and Roblox window, then click **Start Fishing**.
4. Press **P** inside Roblox to begin. Spam **M** at any time to immediately stop FischMate and release all active inputs.

You can run `Create FischMate Shortcut.vbs` once if you want to generate a local `FischMate.lnk` shortcut for this copy.

## No Bundled Executable

FischMate is distributed directly as readable Python and VBScript source/script files.

The package does **not** contain a bundled `.exe`, `.bat`, `.cmd`, or PowerShell launcher.

Because FischMate is distributed in readable script form, users can directly open files such as `.py` and `.vbs` files and inspect the code that makes up the software.

A normal Python 3 installation is required on Windows.

During first-time setup, FischMate installs its required Python libraries into the local `.packages` directory. It does not create a virtual environment and does not intentionally modify your globally installed Python packages.
